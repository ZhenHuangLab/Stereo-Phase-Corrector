# 反相修正

一个本机处理音频的 Chromium Manifest V3 扩展。用于左右声道极性相反、合成单声道后人声抵消的视频，适合配合 Mimi 的系统声音采集使用。

## 安装

下载本仓库的 ZIP 并解压，或克隆源码：

```sh
git clone https://github.com/ZhenHuangLab/Stereo-Phase-Corrector.git
```

下文中的「本文件夹」指包含 `manifest.json` 的 `Stereo-Phase-Corrector` 文件夹。

在 Ardia 的地址栏打开 `chrome://extensions/`（地址栏可能显示 `ardia://extensions`），开启 **Developer mode**，点击 **Load unpacked** 并选择本文件夹。安装成功后页面会显示「反相修正」。从 **Extensions** 菜单打开，也可将它固定到工具栏。每个浏览器配置单独安装，请使用播放视频的同一配置。

在 Chrome 打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」，选择本文件夹。

安装后请保留文件夹，浏览器会直接读取这里的文件。更新文件后，在浏览器扩展管理页重新加载此扩展。

## 使用

1. 播放有问题的视频，从浏览器工具栏或 Extensions 菜单打开「反相修正」。
2. 开启唯一的「启用修正」开关，再运行 Mimi 的系统声音字幕。
3. 关闭开关可立即恢复原声。刷新或切换视频网址时自动恢复；只是切到其他浏览器标签页不会停止。

扩展每次只处理一个标签页。如果另一标签页已启用，面板会说明正在处理哪一页；先关闭，再开启即可切换到当前页。

正常视频保持开关关闭。它是手动修正工具，不自动判断录音质量。没有权限的浏览器内部页面不能处理。跨域跳转后需要重新点击扩展以授予临时访问权。

## 音频处理

输入左声道原样输出到左侧，右声道乘以 −1 后输出到右侧。没有左右合并、左右互换或单边静音。单声道输入先按标准扬声器规则扩展到两个声道。处理错误录音的极性后，其原来异常的空间感会改变。

采用 `tabCapture` 和 offscreen 页面处理整个标签页的声音，避免修改网站播放器自己的 Web Audio 连接。保留标签页原有的静音控制。停止时释放音频采集和 AudioContext，浏览器恢复原本的播放路径。浏览器会显示音频采集提示，这是处理声音所需的状态。

## 隐私与兼容性

音频仅在本机处理，不录制、不保存、不上传。无需 API Key、网络服务或访问所有网站的权限。仅申请 `activeTab`、`tabCapture` 和 `offscreen`。

需要提供这些标准接口的 Chromium 116 或更新版本。已在 macOS 15.8.1、Ardia 0.2.40 中加载，原有反相讲座经修正后已确认可以由 Mimi 识别并显示字幕。音频链路已在 44.1、48、96 kHz 下检查独立双声道、反相输入、单声道输入和静音，共 12 项通过。JavaScript 语法、清单权限和资源引用检查通过。某些受保护内容或浏览器策略会限制音频采集，面板会显示错误。
